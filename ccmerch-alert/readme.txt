Merchandise stock alerts for your WooCommerce store.

== Description ==

CCMerch Alert lets you notify customers when out-of-stock merchandise becomes
available again. WooCommerce integration is coming in the next release.

**Features (planned)**

* Back-in-stock email notifications
* Per-product alert subscription widget
* Admin dashboard with subscriber management
* Customisable notification templates

== Installation ==

1. Upload the `ccmerch-alert` folder to `/wp-content/plugins/`.
2. Activate the plugin through the **Plugins** screen in WordPress Admin.
3. Navigate to **CCMerch Alert** in the admin sidebar to configure the plugin.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

WooCommerce integration is planned for an upcoming release. The current version
can be activated independently.
